# Habot LSA Booking API

A Flask REST API for managing Learning Support Assistants (LSAs), parents, bookings, and payments.

## Tech Stack

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Migrate
- SQLite
- Pytest
- Swagger / OpenAPI

## Features

- LSA search
- Parent management
- Booking creation
- Booking validation
- Double-booking prevention
- Payment webhook
- Payment idempotency
- Database migrations
- Automated tests
- Swagger API documentation
